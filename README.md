# Shucares - E-commerce Shoe Website

A responsive e-commerce website for Shucares, a premium shoe brand. This project includes a complete shopping experience with product browsing, cart functionality, payment processing, and user authentication.

## Features

- **User Authentication**: Login system with form validation
- **Product Showcase**: Featured products and new arrivals sections
- **Shopping Cart**: Add, remove, and manage items with size selection
- **Checkout System**: Complete payment flow with credit card processing
- **Dark Mode**: Toggle between light and dark themes
- **Responsive Design**: Works on mobile, tablet, and desktop
- **Search Functionality**: Search products by keywords

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome 6.6.0 for icons

## Pages/Sections

- Home/Hero Section
- Featured Products
- New Arrivals
- Promotional Banners
- Newsletter Signup
- About Section
- Contact Information
- Footer with Social Media Links

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser

## Structure

- `index.html` - Main HTML structure
- `style.css` - Stylesheet for the application
- `script.js` - JavaScript functionality
- `images/` - Directory containing all product and UI images

The website includes:
